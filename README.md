

# Hi! 👋 I'm Anna / Ankey

IT Support Specialist exploring the world of Networking & Network Security

I've been working in IT support for over 4 years and trying to change my path into Network. My day-to-day work involves troubleshooting technical issues, supporting users, managing access and working with Windows and Azure Virtual Desktop environments.

Over time, I've become increasingly interested in networking and network security. I enjoy understanding how networks work, troubleshooting connectivity issues and learning how different technologies communicate with each other.

I'm currently preparing for the CCNA certification and using Cisco Packet Tracer to put networking concepts into practice. This GitHub profile is where I document my labs, configurations and progress along the way.
